### Создание и настройка сети подразумевает базовую настройку коммутаторов как видим в топологии, будет приведен пример настройки 1 коммутатора

### С консоли PC-A по команде interface F0/1 видим Мак-адрес коммутатора S1 Fast Ethernet 0002.17ca.9301
![image](https://github.com/user-attachments/assets/2379a215-7e25-4a63-8661-14b25ec15f63)
